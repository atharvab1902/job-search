# Interview Prep - Java Full Stack Developer at DEXIAN

## Likely Technical Questions

### Java & Backend
1. **Explain the difference between HashMap and ConcurrentHashMap**
   - HashMap is not thread-safe, ConcurrentHashMap allows concurrent access with segment locking

2. **What is Spring Boot and why use it?**
   - Convention over configuration, embedded server, auto-configuration, production-ready features

3. **How do you handle database transactions in Java?**
   - @Transactional annotation, ACID properties, rollback scenarios

4. **REST API best practices?**
   - Proper HTTP methods, status codes, versioning, pagination, error handling

### Frontend (Angular/React)
1. **Component lifecycle in Angular**
   - ngOnInit, ngOnChanges, ngOnDestroy, change detection

2. **State management approaches**
   - Services with BehaviorSubject, NgRx, or simple component state

### Database
1. **How do you optimize slow SQL queries?**
   - Indexes, EXPLAIN ANALYZE, query restructuring, caching

2. **Difference between SQL and NoSQL?**
   - Schema vs schema-less, ACID vs eventual consistency, use cases
